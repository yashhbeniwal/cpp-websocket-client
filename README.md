# 🔌 WebSocket Client (C++)

A C++ based WebSocket client for real-time message communication using WebSocket++.

---

## 🚀 Overview
This project demonstrates how to establish a WebSocket connection, send messages, and receive responses asynchronously using C++.

---

## ✨ Features
- Real-time bidirectional communication
- Asynchronous networking using ASIO
- Graceful error handling
- Command-line interface

---

## 🛠️ Tech Stack
- C++
- WebSocket++
- ASIO

---

## 🧪 Testing
- Tested using a local WebSocket echo server
- Executed in Linux (WSL) environment
